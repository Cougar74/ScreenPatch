## ✨ Возможности

| | |
|---|---|
| 📌 **Снимки поверх окон** | Каждый снимок открывается в отдельном окне. Его можно перемещать и изменять по размеру. Основного окна у программы нет. |
| ✂️ **Выделение области** | Нажмите `Ctrl + Shift + S` и выделите нужную часть экрана. |
| 🪟 **Снимок с окнами программы** | Нажмите `Ctrl + Alt + Shift + S`, чтобы оставить на картинке видимые окна ScreenPatch. Обычный снимок по-прежнему их не включает. |
| 🔄 **Обновление снимка** | Нажмите `R`, чтобы повторно захватить исходную область. Снимок с окнами программы сохраняет их и при обновлении. |
| 💬 **Подсказки кнопок** | Если задержать курсор на кнопке, появляется её название. |
| 🔀 **Сравнение «до/после»** | После обновления переключайтесь между прежним и новым изображениями. |
| 📋 **Копирование и сохранение** | Копируйте отображаемый снимок в буфер обмена или сохраняйте PNG в исходном разрешении. |
| 🖥️ **Поддержка нескольких мониторов** | Физический размер изображения сохраняется при перемещении между мониторами с разным масштабом. |
| 🌍 **Русский и английский** | При первом запуске язык выбирается по Windows; сменить его можно в трее. |
| 🔒 **Данные остаются у вас** | ScreenPatch не делает собственных сетевых запросов. Снимки остаются на компьютере. |

## 🚀 Быстрый старт

**Для Windows:** [скачайте `ScreenPatch.exe`](release/ScreenPatch.exe) из репозитория и запустите. Программа появится в системном трее, без главного окна.

1. Нажмите **`Ctrl + Shift + S`** или выберите **«Новый снимок»** в трее.
2. **Выделите** нужную область экрана.
3. **Переместите или измените размер** снимка и продолжайте работать.
4. **Щёлкните правой кнопкой** по изображению, чтобы открыть кнопки: **Обновить · До/после · Копировать · Сохранить · Закрыть**.

**Подсказка:** `Ctrl + Alt + Shift + S` выделяет область так же и оставляет на картинке видимые окна ScreenPatch. `R` обновляет исходную область, `1` возвращает исходный физический размер, `Esc` отменяет выделение.

## 💡 Для каких задач пригодится

- **Разработчикам:** держать перед глазами требования, пример кода или текст ошибки.
- **Дизайнерам:** сопоставлять макет с референсом, не переключаясь между окнами.
- **Тестировщикам:** обновлять снимок интерфейса и сравнивать состояние «до» и «после».
- **В повседневной работе:** закреплять инструкции, графики и фрагменты таблиц.

## ⌨️ Управление

| Действие | Как выполнить |
|---|---|
| Новый снимок | `Ctrl + Shift + S` или меню в трее |
| Снимок с окнами программы | `Ctrl + Alt + Shift + S` |
| Выделить область | Зажать левую кнопку мыши и потянуть |
| Отменить выделение | `Esc` |
| Переместить снимок | Перетащить изображение |
| Изменить размер | Потянуть за угол |
| Показать / скрыть кнопки | Правая кнопка мыши по снимку |
| Обновить исходную область | `R` при активном снимке |
| Вернуть исходный размер | `1` при активном снимке |
| Копировать / сохранить / закрыть | Кнопки после правого щелчка |
| Показать / скрыть / закрыть все | Меню в трее |

Команда **«Справка»** в трее открывает список сочетаний и действий. После закрытия последнего снимка программа продолжает работать в трее; для завершения выберите **«Выход»**.

## 🛠️ Сборка из исходного кода

Нужны **Windows**, стабильный **Rust** и **MSVC toolchain**.

```powershell
git clone https://github.com/Cougar74/ScreenPatch.git
cd ScreenPatch
cargo build --release
```

Результат: `target/release/ScreenPatch.exe`. Для запуска из исходников можно использовать `cargo run`.

## ⚠️ Известные ограничения

Версия 0.3.0 работает только в **Windows** и поддерживает до **10** открытых снимков. Общий бюджет памяти для текущих и предыдущих кадров — **512 МиБ**, максимальный размер одного кадра — **64 МиБ**. Автообновления, восстановления сессий и привязки снимка к окну другого приложения пока нет. Если изменилось разрешение или масштаб исходного монитора, обновление может не работать до восстановления прежних параметров.

Полный список — в [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md).
