# ScreenPatch

[English](README.md)

Copyright 2026 Eduard

## Что делает программа

ScreenPatch держит снимки в отдельных окнах поверх обычных окон. Главного окна нет.

## Требования

Windows и стабильный Rust с MSVC. Номер компилятора репозиторий не фиксирует.

## Сборка

```
cargo build --release
```

Сборка записывает `target/release/screenpatch.exe`. Этот путь в git не входит. Готовый файл этой версии — [release/screenpatch.exe](release/screenpatch.exe).

## Запуск

Запустите `release/screenpatch.exe` или `cargo run`. Появляется значок в трее, окон нет. Повторный запуск сразу завершается и второй значок не создаёт.

## Язык

Первый запуск следует языку интерфейса Windows. Русская Windows показывает русские подписи, любой другой язык — английские. Пункт «Переключить на English» или «Change to Русский» в трее сразу переключает язык и запоминает выбор. Следующий запуск использует этот выбор вместо языка Windows. «Выход» стоит ниже разделителя.

## Снимок

Нажмите Ctrl+Shift+S или выберите «Новый снимок». Выделите область. Область меньше 16×16 окно не создаёт. Esc закрывает только выделение.

Новое окно совпадает со снимком: один пиксель экрана на один пиксель кадра. Полоса кнопок скрыта. Правый клик показывает полосу, второй правый клик её прячет. Картинка сохраняет физический размер. На полосе: «Обновить» (Refresh), «До/после» (Before/after), «Копировать» (Copy), «Сохранить» (Save) и «Закрыть» (Close).

Перетаскивание картинки двигает окно. Угол меняет размер. Минимум 120×80 действует только на этот угол. Клавиша `1` возвращает исходный физический размер и сдвигает окно в рабочую область. `R` снимает ту же область заново. Перенос окна на монитор с другим масштабом не меняет физический размер картинки.

## Окна

«Показать все» и «Скрыть все» меняют видимость и не меняют картинки. «Закрыть все снимки» спрашивает подтверждение. «Выход» убирает значок и завершает процесс. Закрытие последнего окна процесс не завершает.

## Приватность

Захват, буфер обмена и выбранный PNG остаются на этом компьютере. Своих сетевых запросов ScreenPatch не делает.
