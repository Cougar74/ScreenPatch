# ScreenPatch

[English](README.md)

Copyright 2026 Eduard

## Что делает программа

ScreenPatch держит снимки в отдельных окнах поверх обычных окон. Главного окна нет.

## Требования

Windows и стабильный Rust с MSVC. Номер компилятора репозиторий не фиксирует.

## Сборка

```
cargo build --release
```

Сборка записывает `target/release/ScreenPatch.exe`. Этот путь в git не входит. Готовый файл этой версии — [release/ScreenPatch.exe](release/ScreenPatch.exe).

## Запуск

Запустите `release/ScreenPatch.exe` или `cargo run`. Появляется значок в трее, окон нет. Повторный запуск сразу завершается и второй значок не создаёт.

## Язык

Первый запуск следует языку интерфейса Windows. Русская Windows показывает русские подписи, любой другой язык — английские. «Язык» или Language открывает «Русский» и English, у текущего стоит галочка. Выбор другого языка сразу переключает интерфейс и запоминает выбор. Повторный выбор текущего языка ничего не меняет. Следующий запуск использует этот выбор вместо языка Windows.

## Снимок

Нажмите Ctrl+Shift+S или выберите «Новый снимок». Выделите область. Область меньше 16×16 окно не создаёт. Esc закрывает только выделение.

Новое окно совпадает со снимком: один пиксель экрана на один пиксель кадра. Кнопки сначала скрыты. Правый клик показывает их, второй правый клик прячет. Картинка сохраняет физический размер. Кнопки круглые, с иконками: обновить, до и после, копировать, сохранить и закрыть.

Перетаскивание картинки двигает окно. Угол меняет размер. Минимум 120×80 действует только на этот угол. Клавиша `1` возвращает исходный физический размер и сдвигает окно в рабочую область. `R` снимает ту же область заново. Перенос окна на монитор с другим масштабом не меняет физический размер картинки.

## Окна

«Показать все» и «Скрыть все» меняют видимость и не меняют картинки. «Закрыть все снимки» спрашивает подтверждение. «Справка» или Help открывает одно окно со списком горячих клавиш и действий мыши. Esc или крестик его закрывает. Повторный выбор «Справка», пока окно открыто, показывает его на том же месте. Перед «Язык» стоит разделитель, «Выход» стоит ниже второго. «Выход» убирает значок и завершает процесс. Закрытие последнего снимка процесс не завершает. Показать, скрыть и закрыть все снимки справку не трогают.

## Приватность

Захват, буфер обмена и выбранный PNG остаются на этом компьютере. Своих сетевых запросов ScreenPatch не делает.
